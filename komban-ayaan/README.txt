KOMBAN AYAAN — Kerala Catch Game

FILES
- index.html: complete game code (HTML, CSS and JavaScript)
- assets/komban-catcher.png: your supplied character image
- assets/komban-theme.mp3: the audio file you supplied, set to loop

HOW TO TEST
1. Keep the index.html file and the assets folder together.
2. Open index.html in a modern browser, or upload the whole komban-ayaan-game folder to your website.
3. Press START GAME to begin and allow audio playback.
4. Move with left/right arrow keys, A/D, on-screen buttons, or touch/drag.

SCORING
Elephant face: +5
Sugarcane: +3
Coconut leaves: +1
Five missed items ends the game.

GITHUB PAGES
Upload the folder contents to a folder named komban-ayaan (or any folder you choose). Keep index.html directly inside that folder and keep assets/ beside it. Visit /your-folder-name/ on your site.

NOTE
Browsers usually block autoplay until the player presses Start; the supplied audio starts looping after Start. The supplied MP3 is included as provided by you.
