VASU DOBU - complete website game folder

Files:
  index.html                 Game (the catcher image is embedded in the HTML)
  vasu.png                   Separate copy of your transparent catcher image
  who-let-the-dogs-out.mp3   Supplied soundtrack, configured to loop
  README.txt                 These instructions

To add to your website, upload the entire vasu-dobu folder to the root of your website repository.
Keep the files together. Open the game at: https://YOUR-SITE/vasu-dobu/

The music starts after the player presses PLAY because browsers block autoplay before user interaction. The Sound button controls the music and game sound effects.
Make sure you have the necessary rights to publish the supplied music.
